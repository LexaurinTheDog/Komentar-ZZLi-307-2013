# Komentář k zákonu č. 307/2013 Sb., o povinném značení lihu

Otevřený komentář k zákonu o povinném značení lihu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; značení lihu kontrolní páskou, registrace osoby povinné značit líh, nakládání s kontrolními páskami, distribuce lihu a registrace distributora, prověřování plnění povinností, přestupky a propadnutí či zabrání neznačeného lihu.

Konsolidované znění: dokument e-Sbírky `SB-2013-00307_2025-07-01`.
